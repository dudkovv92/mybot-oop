# Модульный Telegram-бот на Python 🤖

Телеграм-бот с модульной архитектурой (разделение на `bot.py`, `db.py` и `main.py`). 
Умеет сохранять данные пользователей в SQLite, а также имеет набор команд и кнопок.

## 🛠 Стек:
* **Язык:** Python
* **Библиотека:** pyTelegramBotAPI
* **База данных:** SQLite
* **Тестирование:** pytest
* **Инструменты:** Git, venv

## 📂 Структура проекта:
* `main.py` — точка входа (запуск бота).
* `bot.py` — логика команд и обработка сообщений.
* `db.py` — работа с базой данных (класс DB).
* `test_db.py` — тесты для проверки базы.
* `requirements.txt` — зависимости проекта.

## 🚀 Как запустить:
1. Склонируйте репозиторий.
2. Создайте и активируйте виртуальное окружение: `python -m venv venv` и `venv\Scripts\activate`.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Создайте файл `.env` и добавьте туда токен: `TOKEN=ваш_токен_от_BotFather`.
5. Запустите: `python main.py`.
